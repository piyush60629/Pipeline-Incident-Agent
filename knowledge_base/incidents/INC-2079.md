# INC-2079: Silver sales join out of memory on one store

- Date: 2026-08-15
- Pipeline: pl_transform_silver_sales
- Symptom: ExecutorLostFailure and Java heap space errors in the join stage.
- Root cause: Data skew; one store had most of the day's transactions, so one task processed most of the data.
- Resolution: Enabled AQE skew join handling for the run and broadcast the stores dimension; batch rerun.
- Prevention: The setting was not made permanent in the job configuration (follow-up DE-327 open).
